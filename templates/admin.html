Scraper controls

Choose a US or Canadian city or town from the suggestions. Results depend on the available source for that location; this is not a comprehensive search of social media or classified sites.

Suggestions use OpenStreetMap data via Photon and cover places across the US and Canada. eBrandon currently provides garage-sale listings for Brandon, Manitoba. An optional Ticketmaster API lookup can return exact garage-sale or yard-sale event matches, but is not a general garage-sale feed.

Create a listing from a screenshot

Choose a screenshot, extract the text, review the draft, and save it. OCR runs in this browser; the image is not uploaded to YardScout or sent to an OCR service.

The OCR library and language data are downloaded from a public CDN. Review all extracted details against the original post before saving.
